## Как подключить (5 минут)
1. Опубликуй игру (см. [[Как открыть и запустить]]).
2. [create.roblox.com](https://create.roblox.com) → твоя игра → **Monetization → Passes** → Create a Pass (картинка, название, цена) → скопируй **Pass ID**.
3. **Monetization → Developer Products** → Create → скопируй **Product ID**.
4. Открой `ReplicatedStorage → Shared → Config` и вставь Id вместо `Id = 0`.
5. Пока Id = 0, кнопка показывает «Скоро в продаже».

> [!tip] Тест в Studio
> `Config.StudioFreePasses = true` — все геймпассы считаются купленными, только в Studio.

Покупки защищены от двойного начисления (список последних покупок в сохранении игрока).
