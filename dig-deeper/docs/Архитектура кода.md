# Архитектура кода
Язык: **Luau**. Структура совместима с **Rojo** (`default.project.json`).

## Общие модули — `src/shared` → ReplicatedStorage.Shared
| Файл | Что внутри |
|---|---|
| `Config.luau` | **все цифры и цены**: слои, кирки, рюкзаки, геймпассы, награды, коды, звуки |
| `Economy.luau` | формулы: множители, цены перерождения, вместимость, скорость, награды |
| `Locale.luau` | все тексты RU/EN, форматирование чисел ($12.5K) |

## Сервер — `src/server` → ServerScriptService.Server
| Файл | Что делает |
|---|---|
| `Main.server.luau` | запуск, таймер обновления шахты |
| `Remotes.luau` | каналы Mine / Action / State / Fx |
| `DataService.luau` | сохранения (DataStore), автосейв |
| `MineService.luau` | «ленивая» шахта: блоки появляются только видимые |
| `PlayerService.luau` | копание (проверки), продажа, магазин, перерождение, лифт, награды, коды, кирка в руках |
| `PurchaseService.luau` | геймпассы и покупки, защита от двойного начисления |
| `LeaderboardService.luau` | доски «Топ глубины» и «Топ ребёртов» |

## Клиент — `src/client` → StarterPlayerScripts.Client
| Файл | Что делает |
|---|---|
| `Main.client.luau` | связывает всё, обрабатывает события сервера |
| `UIKit.luau` | детали интерфейса: кнопки, карточки, бейджи, полоски |
| `HUD.luau` | главный экран, цель, тосты |
| `Windows.luau` | 6 окон |
| `Mining.luau` | копание, рамка и прочность блока |
| `Effects.luau` | осколки, пыль, монеты, конфетти, вспышки, тряска |
| `Cutscenes.luau` | все катсцены |
| `Ambience.luau` | свет, туман, цвет по слоям, пыль |
| `World.luau` | надписи на табличках, круги, вращение |

## Инструменты — `tools/`
- `build_place.py` — собирает `build/DigDeeper.rbxlx` (карта + скрипты) и `build/Map.rbxmx`.
- `lint.js` — проверка синтаксиса и опечаток. `test_shared.js` — 60 тестов экономики.
- `preview/index.html` — 3D-превью карты (three.js).
