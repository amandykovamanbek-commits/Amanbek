# Карта острова

Парящий остров 288×288 studs, высота поверхности **Y = 6100** (шахта уходит вниз на 6000 studs).
Трава в клетку со «студами», как в топовых симуляторах. Карта — обычные детали Roblox в `Workspace → Map`: их можно двигать, перекрашивать и удалять прямо в Studio.

## Что где стоит
| Объект | Где | Что делает |
|---|---|---|
| Спавн + дорожка с жёлтыми стрелками | юг (0, −120) | ведёт к шахте |
| Арка «⛏ ШАХТА» | южный край шахты | вход |
| Шахта 16×16 блоков | центр | копать |
| 💰 Лавка (красный круг) | запад | **автопродажа** при входе в круг |
| ⛏ Кузница (оранжевый круг) | северо-запад | магазин кирок |
| 🎒 Рюкзаки (синий круг) | северо-восток | магазин рюкзаков |
| 🔄 Алтарь перерождения (фиолетовый) | восток | окно перерождения |
| 🎁 Сундук наград (зелёный) | юго-запад | ежедневные награды и коды |
| 🛗 Башня лифта (жёлтый) | юго-восток | спуск на открытые слои |
| Вывеска «КОПАЙ ГЛУБЖЕ» + 2 доски лидеров | север | видно со спавна |
| Золотая кирка-памятник, вагонетка, кристаллы | вокруг шахты | красота |
| Деревья, кусты, цветы, камни, облака, парящие острова | везде | красота |

## Как устроены «умные» детали
- **Табличка** = деталь с `StringValue` **SignKey** (например `Title`). Текст рисуется у каждого игрока на его языке (тексты в `Locale.luau`, ключи `Sign_...`).
- **Круг** = деталь с `StringValue` **PadKind** (`Sell`, `PickShop`, `BagShop`, `Rebirth`, `Elevator`, `Daily`).
- **Вращается** = деталь с `StringValue` **Spin** (значение — скорость).
- **Доска лидеров** = деталь `Leaderboard` с `StringValue` **Board** (`Depth` или `Rebirths`).

Можно копировать эти детали (Ctrl+D) и ставить куда угодно — всё заработает.

## Пересобрать карту кодом
`python3 tools/build_place.py` — генератор карты (позиции, цвета, деревья). Превью: `tools/preview/index.html`.
