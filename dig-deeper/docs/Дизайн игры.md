# Дизайн игры

## Идея
Ты — шахтёр на парящем острове. Посреди острова — шахта глубиной **1000 метров** до **ядра планеты**. Чем глубже — тем дороже руда, но нужны кирки посильнее.

## Игровой цикл (30 секунд)
1. Копаешь блоки вниз → руда падает в рюкзак (`+1 Сапфир`).
2. Рюкзак полон → нажимаешь **Наверх** или **Лифт** → встаёшь в красный круг → деньги летят в счётчик.
3. Покупаешь кирку получше / рюкзак побольше → копаешь глубже.
4. Нашёл новый слой → катсцена «НОВЫЙ СЛОЙ!» + награда.
5. Накопил $1M → **перерождение**: всё сначала, но доход навсегда +50%.

## Что держит игроков
| Механика | Зачем |
|---|---|
| 🎯 Цель в углу экрана | Новичок всегда знает, что делать дальше |
| 🎁 Награда каждый день (7 дней) | Возвращаются завтра |
| 🎟 Коды | Для видео на YouTube: «новые коды!» |
| 🏆 Доски лидеров | Соревнование по глубине и ребёртам |
| 🔄 Перерождение | Бесконечный прогресс |
| ⚠ Обновление шахты каждые 20 мин | Свежая шахта, землетрясение — событие |
| 🛗 Лифт | Не надо копать заново к открытому слою |

## Отличия от конкурентов
- Настоящая 3D-шахта из блоков с **6 разными слоями** и своей атмосферой (туман, свет, пыль).
- **Катсцены** — редкость в симуляторах, делают игру «дорогой».
- Два языка (RU/EN) — переключение одной кнопкой.
