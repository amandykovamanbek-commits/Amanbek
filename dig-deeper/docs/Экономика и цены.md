## 🔄 Перерождение
- Цена: $1M, дальше каждое **x2.5** ($2.5M, $6.25M…).
- Даёт навсегда **+50% дохода** за каждое.
- Сбрасывает деньги, кирку, рюкзак. Рекорд глубины и открытые слои остаются.

## 🎁 Ежедневные награды (по кругу 7 дней)
$500 → $1K → зелье скорости → $2.5K → зелье удачи → $10K → $25K + зелье удачи.
Деньги умножаются на (1 + перерождения) × номер кирки. Пропустил больше 48 часов — серия сначала.

## 🎟 Коды
`RELEASE` (+$1 000), `DIGDEEP` (+$2 500), `LUCKY` (зелье удачи). Добавлять в `Config.Codes`.

## Темп (примерно)
- Первая кирка — 1–2 минуты.
- Слой «Лава» — ~30–40 минут.
- Первое перерождение — ~2–3 часа без покупок.
