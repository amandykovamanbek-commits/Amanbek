# Как открыть и запустить

## 1. Открыть игру (без Rojo и без настроек)
1. Скачай файл **`DigDeeper.rbxlx`** (из чата или из GitHub: `dig-deeper/build/DigDeeper.rbxlx`).
2. Открой его **двойным кликом** — запустится Roblox Studio с готовой игрой.
3. Нажми **Play** (F5). Покажется интро-катсцена, потом можно копать.

> [!tip] Управление
> - **ПК:** зажми левую кнопку мыши на блоке — копаешь.
> - **Телефон:** зажми палец на блоке или кнопку **⛏ КОПАТЬ** справа внизу.
> - Встань в цветной круг у лавки — откроется магазин. Красный круг — продажа руды.

## 2. Включить сохранения (один раз)
В Studio: **Game Settings → Security → Enable Studio Access to API Services** → Save.
Без этого игра работает, но прогресс не сохраняется (в игре будет сообщение).

## 3. Опубликовать в Roblox
**File → Publish to Roblox** → придумай название и описание → Create.
Потом на [create.roblox.com](https://create.roblox.com) можно сделать игру публичной.

## 4. Геймпассы и покупки
Смотри [[Монетизация]]: создать на сайте → вставить Id в `Config.luau`.

## 5. Если работаешь через Rojo (по желанию)
Проект `default.project.json` уже настроен: `rojo serve` в папке `dig-deeper`, в Studio — Plugins → Rojo → Connect.
Карта лежит в `build/Map.rbxmx`. После правок карты запусти `python3 tools/build_place.py`.

## Проверки кода (для разработчика)
```
node tools/lint.js          # синтаксис и опечатки в именах
node tools/test_shared.js   # 60 тестов экономики и текстов
python3 tools/build_place.py # собрать DigDeeper.rbxlx
```
