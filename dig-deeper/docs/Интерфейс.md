# Интерфейс

Макеты: [Figma — Копай глубже UI](https://www.figma.com/design/1cKP3hDkn4fBIRNBIwlKoe) (v1 — тёмный стиль, **v2 — яркий, по нему сделана игра**).

## Стиль (как в топовых симуляторах)
- Яркие **градиенты** сверху вниз, **толстая чёрная обводка** (3–5 px), текст **с обводкой**.
- Окна: цветная шапка с косыми полосками, красный ✕, тёмное тело.
- Карточки товаров: градиент цвета предмета, иконка в кольце, плашка характеристики, большая кнопка цены.
- Бейджи: «СЛЕДУЮЩАЯ», «ЛЕГЕНДА» (радуга), «ХИТ!», «ВЫГОДНО», «САМОЕ ВЫГОДНОЕ».
- Кнопки «пружинят» при наведении и нажатии.

## Цвета кнопок
| Цвет | Значение |
|---|---|
| 🟩 зелёный | купить / продать / забрать |
| 🟨 золотой | надето |
| ⬜ серый | есть / закрыто |
| 🟥 красный | закрыть / ошибка |
| 🟦 синий | вкладки, покупки за Robux |
| 🟪 фиолетовый | перерождение, премиум |

## Шрифты
- Русский: **Gotham Black** (в Figma — Montserrat Black) — есть кириллица.
- English: **Fredoka One** — как в популярных играх.

## Экраны
- **HUD:** внизу слева 🎒 рюкзак / ⛏ сила / 💰 деньги; слева — Магазин, Ребёрт, Рюкзак; справа — Премиум, Награды, Лифт, Наверх; сверху — глубина и полоска до следующего слоя; справа сверху — 🎯 Цель; зелья; кнопки АВТО и 🌐 язык; на телефоне — большая ⛏ КОПАТЬ.
- **Окна:** Магазин (кирки/рюкзаки), Продажа, Премиум, Перерождение, Награды + коды, Лифт.

Всё рисуется кодом: `src/client/UIKit.luau` (детали), `HUD.luau`, `Windows.luau`. Масштаб подстраивается под любой экран (база 1280×720).
