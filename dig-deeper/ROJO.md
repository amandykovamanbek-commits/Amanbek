# Подключение Rojo (Windows)

1. Скачай Rojo: https://github.com/rojo-rbx/rojo/releases — файл `rojo-<версия>-windows-x86_64.zip`.
   Распакуй `rojo.exe` в эту папку (`Amanbek/dig-deeper`).
2. Плагин: открой Roblox Studio, затем в командной строке Windows в этой папке:
   `.\rojo.exe plugin install`  (или найди "Rojo" в Toolbox → Plugins).
3. Studio → создай Baseplate (New → Baseplate).
4. В этой папке: `.\rojo.exe serve`  — окно не закрывай.
5. Studio → вкладка Plugins → Rojo → Connect.
6. Нажми Play. В Output должно быть: `[Dig Deeper] Rojo подключён!` и над спавном — оранжевый куб.
