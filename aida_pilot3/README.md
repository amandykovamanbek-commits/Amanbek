# «Айда!» — пилот 3 (комикс-страницы, HyperFrames)

**`pilot3.mp4`** — 23 с, 1920×1080, 30 fps (сжатая копия для просмотра; полное качество — перерендерить).

Тот же текст, голос (`assets/audio/voice.mp3`, Fuad) и кадры Flow, что в `aida_pilot2/`, но смонтировано
навыком **HyperFrames** (HTML + GSAP → видео) в виде комикс-страниц:

- панели с чёрной рамкой на «бумаге» с полутоновым растром; разные входы панелей (проявление, въезд с наклоном,
  хлёсткий перелист, диагональная шторка);
- жёлтые подписи-плашки и «слэм»-надписи (Roboto Condensed с обводкой) точно по таймингу слов (`aida_pilot2/timing.json`);
- удар: разгон кулака в камеру, вспышка, тряска, звёздочка «БАМ!»; кардиограмма в больнице; шёпот по словам;
  финальная карточка «Продолжение следует…»; детерминированный снег в сценах 1 и 7.
- звук: `voice.mp3` (1.0) + `sfx.mp3` (дрон/удары из пилота 2, 0.55).

## Структура
- `index.html` — корень: 7 сцен + две аудиодорожки.
- `compositions/s1.html … s7.html` — сцены (одна сцена = один файл, тайминги в атрибутах `data-start`/`data-duration`).
- `assets/` — кадры, голос, sfx, шрифт.

## Команды (Node 22+, ffmpeg)
```
npx hyperframes check              # линт + раскладка
npx hyperframes snapshot --at 3,10 # кадры для проверки
npx hyperframes render --output pilot3_full.mp4
```
Править удобно в бесплатном HyperFrames desktop app (таймлайн, тексты, тайминги).
