# Башня, которую спасли лопатой (рабочее название)

Вертикальный мультшортс в стиле скилла `cartoon-3d-short`. Озвучка на русском через ElevenLabs: это ваш выбор, он
отменяет правило скилла «English only». Чистый текст для озвучки лежит в `voice_ru.txt`.

## 1. Сверка темы с каналом-образцом
- Получил список всех роликов канала через yt-dlp: 151 шортс, вкладки с длинными видео у канала нет. Список в
  `research/channel_shorts.tsv`.
- Ни в одном названии нет Пизы, башен, наклона, грунта или фундамента (grep `pisa|tower|lean|soil|clay|foundation` = 0).
- Ближе всего по жанру их инженерные ролики: «Why Perfect Railroads Don't Work», «This Shape Saved Roller Coasters»,
  «Why Sailors Carried Storm Oil». Там другие явления (зазоры рельсов, форма петли, масло на волнах), не грунт.
- Пример из самого скилла, «The Bridge That Fell for a Song», про резонанс моста. Наша тема про мягкий грунт и
  противовес, механика другая, повтора нет.
- Ограничение: сами ролики канала скачать нельзя (googlevideo.com закрыт сетью окружения), поэтому сверка идёт по
  названиям, а не по содержанию.

## 4. Набросок мира и героев (для шага 3, без шотлиста)
- Мир: Площадь Чудес (Пьяцца-дей-Мираколи) — белый мрамор, зелёный газон, собор и сама башня. Тот же мир в трёх
  эпохах: средневековая стройка, 1934 год, 1990-е.
- Свет по тактам: день для XII века, золотой час для 1934 и «Чёрного сентября», снова день для развязки.
- Герои (свои, бобовидные): каменщики XII века, строитель с отвесом, Муссолини-карикатура в профиль, инженер в каске
  с буром, мальчик на мокром песке для аналогии, туристы, которые «держат» башню на фото (финал).
- Опасные места для читаемости: свинцовые чушки должны читаться как металл, а не как камни. Бур под башней показать
  в разрезе, иначе непонятно, откуда берут землю.
