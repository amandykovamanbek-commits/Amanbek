# «Күзгі асар» жәрменкесі — motion design видео (Remotion)

**Не это:** визуальная презентация мерекелік шара для мектепалды даярлық тобы (МАД):
«Күзгі асар» жәрменкесі + «Табиғатқа қамқорлық жасаймыз» акциясы.
**Для кого:** тәрбиешілер, ата-аналар, әдіскер — показать на педсовете / в соцсетях.
**Угол:** «асар» = бірлесіп көмектесу. Жәрменке и забота о природе — одно общее дело.
**Хук:** падающие кленовые листья складываются в заголовок «Күзгі асар».
**Панчлайн:** «Бірлік бар жерде — тірлік бар!»

Длительность: ~89 с (содержание конспекта — 7 разделов; каждый текст держится ≥0.3 с/слово).
Формат: 1920×1080, 30 fps. Темп музыки 100 BPM → 1 такт = 2.4 с = 72 кадра, все склейки на долях.

Стиль: плоский motion design, тёплая осенняя палитра (крем #FFF3E0, оранжевый #EE6A1F,
горчичный #F2B227, кирпичный #B3361D, лесной зелёный #2E5B3A, тёмный #2A1A10),
шрифт Inter Display (поддерживает ә ғ қ ң ө ұ ү һ і), казахский орнамент «қошқар мүйіз».
