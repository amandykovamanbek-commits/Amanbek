# BILIM QADAM: ролик для жюри (1:15, қазақша)

## Ответы перед планом
- **Что это:** BILIM QADAM — сайт с тестами для 9 класса: 4 предмета (алгебра, геометрия, физика, информатика), темы 1–2 четверти, 40 вопросов.
- **Для кого:** ученики 9 класса и их учителя. Открывается по ссылке или QR-коду на любом телефоне, без пароля.
- **Чем выделяется:** к каждому вопросу есть пошаговое объяснение AI-көмекші (решение, типичная ошибка, задача «Өзіңді тексер»), а результаты сразу попадают в живой рейтинг класса.
- **Самое сильное утверждение:** ошибка — это не конец, а следующий шаг («қадам»). Ученик ошибся, и приложение тут же объясняет, почему.
- **Визуальный крючок:** логотип собирается на экране: кольцо прогресса, лестница из трёх шагов и звезда-цель.
- **Какой UI показать:** настоящий интерфейс сайта (его CSS и разметка) в телефоне: регистрация → выбор предмета → вопрос с ошибкой → AI-объяснение → результат → рейтинг.
- **Тон:** `default` с элементами `app-store`: ясно, бодро, чисто. Ролик для жюри, поэтому без шуток, но живой.
- **Подпись для публикации:** см. `share-copy.txt`.

Длительность 75 с по просьбе пользователя (вместо стандартных 20 с): нужно показать весь путь ученика.

## Визуальная идентичность
- Цвета сайта: ночной тёмно-синий `#0A0F2C` / `#121A46`, карточки `#18225A`, голубой `#38D6F5`, солнечно-жёлтый `#FFC845`, зелёный `#3DDC97`, красный `#FF6B7A`.
- Шрифты сайта: Montserrat 800–900 (заголовки), Inter 400–700 (текст).
- Телефон в центре внимания: внутри настоящие стили `bilim-qadam/public/index.html`, анимации покадровые.
- Имена в интерфейсе вымышленные (Әлия Н., Нұрсұлтан Б. …); настоящие имена команды — только в финальных титрах.

## Музыка
- 120 BPM, такт = 2 с = 60 кадров, доля = 15 кадров. Тональность до мажор, аккорды C–G–Am–F по такту.
- Все склейки и «нажатия» стоят на долях (кратны 15 кадрам). Эффекты (клик, вжух, успех, ошибка, звон) в той же тональности и мягко под музыкой.
