# Дрифт & Шашки

Браузерная 3D-игра про машины с мультиплеером до 5 игроков в комнате.

## Режимы

- **Дрифт.** Площадка в центре карты. Очки за угол заноса, скорость и длительность. Связанные заносы растят множитель (до ×8). Вылет на траву или авария сжигают серию.
- **Шашки.** Кольцевая трасса с плотным потоком (~130 машин). Очки за обгон рядом с машиной на скорости от 72 км/ч, вдвое больше за «впритирку». Каждый обгон в течение 4 секунд повышает множитель (до ×10), авария обнуляет серию.
- **Покатушки.** Та же трасса с редким потоком, без очков.

## Управление

| Клавиши | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз, задний ход |
| A D / ← → | руль |
| Пробел | ручник |
| R | респавн |
| C | дальняя или ближняя камера |
| M | звук |
| Esc | меню |

На телефоне появляются экранные кнопки.

## Запуск локально

```bash
cd drift-game
npm install
npm start
# открыть http://localhost:3000
```

## Деплой на Render

1. Залей репозиторий на GitHub (в нём уже есть `render.yaml` в корне).
2. На https://dashboard.render.com: **New → Blueprint**, выбери репозиторий и ветку. Render сам прочитает `render.yaml`.
   Можно и вручную: **New → Web Service**, Root Directory `drift-game`, Build `npm install`, Start `npm start`.
3. Через пару минут игра откроется по адресу вида `https://drift-game-xxxx.onrender.com`.

На бесплатном тарифе Render усыпляет сервер после 15 минут без посетителей. Первое открытие после этого занимает около минуты. Если сервер засыпает или перезапускается, комнаты пропадают, и их нужно создать заново.

## Как устроено

- `server.js`: Node.js с HTTP и WebSocket (`ws`). Раздаёт файлы из `public/`, хранит комнаты в памяти (код из 4 символов, до 5 игроков) и 15 раз в секунду рассылает позиции игроков.
- `public/game.js`: Three.js.
  - Аркадная физика: боковое сцепление регулируется, ручник и газ срывают машину в занос.
  - Чужие машины плавно интерполируются между снапшотами сервера.
  - Поток машин детерминированный: позиция каждой машины считается из сида комнаты и общего времени сервера, поэтому все игроки видят одни и те же машины, хотя по сети они не передаются.
- Машины игроков проходят друг сквозь друга, столкновения есть только с потоком.
- Каждый клиент сам отвечает за свою позицию, сервер её не проверяет. Для игры с друзьями этого достаточно.
