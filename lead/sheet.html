КОННЕКТОРЫ
И СКИЛЛЫ

Без коннекторов и скиллов Claude только советует. С ними — делает сам: озвучивает, верстает, собирает ролики и сохраняет файлы.

КОННЕКТОР

Руки Claude

Доступ к другим сервисам: ElevenLabs, Figma, Canva, vidIQ, Notion, GitHub.

  1. Открой Настройки → Коннекторы.
  2. Найди сервис в каталоге и нажми «Подключить».
  3. Войди в аккаунт сервиса и разреши доступ.
  4. Нет в каталоге? «Добавить свой коннектор» и вставь адрес MCP сервиса.
СКИЛЛ

Навыки Claude

Готовые инструкции: как сделать задачу по шагам и в нужном формате.

  1. Открой Настройки → Возможности.
  2. Включи выполнение кода и создание файлов.
  3. В разделе «Скиллы» включи нужные или загрузи свой (.zip).
  4. В Claude Code скиллы вызываются командой: /имя-скилла.
Названия пунктов в меню могут немного отличаться — ищи «Коннекторы» и «Скиллы».
Почти всё бесплатно. У сервисов есть бесплатные тарифы; Claude Code — в подписке Pro.

01 · КОННЕКТОР

ElevenLabs

~10 000 симв./мес бесплатно

Озвучка: Claude пишет текст, подбирает голос и озвучивает. Голос из видео — Nikolay.

КАК ПОДКЛЮЧИТЬ

  1. Claude → Настройки → Коннекторы → каталог → ElevenLabs.
  2. Нет в каталоге — «Добавить свой коннектор»: api.elevenlabs.io/v1/mcp
  3. Войди в аккаунт ElevenLabs и разреши доступ.
ПЕРВЫЙ ПРОМПТ

Через ElevenLabs найди 5 русских голосов и пришли их демо.

Потом озвучь этот текст голосом, который я выберу: текст

Notion

бесплатно

База: идеи, контент-план, сценарии. Claude сам записывает туда итоги и продолжает с того же места.

07 · СКИЛЛ

brag-slim

бесплатно

Промо-ролик из проекта или сайта: хук, музыка в бит, текст для поста — одной командой.

КАК ПОДКЛЮЧИТЬ

  1. Открой Claude Code (вкладка «Код»).
  2. Вызови скилл: /brag-slim + папка или ссылка.
  3. Нет такого скилла — попроси skill-creator собрать похожий.
ПЕРВЫЙ ПРОМПТ

/brag-slim папка проекта или ссылка — вертикально, 20–30 секунд, моушен-дизайн.

skill-creator

бесплатно

Скилл, который делает скиллы: объясни задачу один раз — дальше хватит одной команды.

КАК ПОДКЛЮЧИТЬ

  1. Включи skill-creator в разделе «Скиллы».
  2. Сделай задачу вместе с Claude один раз.
  3. Попроси сохранить процесс как скилл.
ПЕРВЫЙ ПРОМПТ

Запомни процесс, который мы только что сделали, и сохрани его как скилл имя. Опиши шаги так, чтобы в следующий раз хватило одной команды.

deep-research

бесплатно
