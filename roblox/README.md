# Wings & Brainrots (Roblox)

Летаешь на крыльях на далёкие острова, хватаешь существ и несёшь на свою базу. Там они приносят $ каждую секунду.

## Как запустить
1. Скачай `WingsAndBrainrots.rbxlx` и открой его в Roblox Studio.
2. Нажми **Play**. Карта, острова и существа появятся при запуске (в режиме редактирования мир пустой, так и задумано).
3. Чтобы работало сохранение: **Game Settings → Security → Enable Studio Access to API Services** (нужно сначала опубликовать игру: File → Publish to Roblox).
4. **Game Settings → Places → Max Players = 4.**

## Управление
- **Пробел** в прыжке и держать → лететь вверх (тратит стамину). Отпустил → плавно снижаешься.
- Стамина кончилась → падаешь. Упал в воду → тебя вернёт на базу, а существо вернётся на остров.
- **E** → схватить существо или открыть станцию.
- На телефоне: кнопка «Лететь».

## Что есть
- Интерфейс в стиле симуляторов: меню слева (⭐ Магазин, 📖 Индекс существ, 🏠 Домой), деньги и доход сверху, таймер божественного справа, стамина снизу. Окна магазинов с карточками, вкладками и кнопкой «МАКС».
- Лобби: 4 базы в ряд, фонтан, магазины, арка «ЗОНЫ» на старте.
- 4 базы со стенами, аркой и 10 подиумами (15 с Game Pass). Доход копится у каждого подиума — наступи на зелёную кнопку, чтобы забрать $.
- Станции в центре: ⚡ Скорость, 💪 Стамина, 🕊 Крылья, 💰 Рынок (продажа), ⭐ Донат.
- Цена прокачки = база × 1.5^уровень.
- 7 крыльев: от x1 до x5 к стамине.
- 7 тематических зон-островов идут **прямой линией** от лобби (как в играх жанра): луг → конфетный лес → пляж → вулкан → ледник → кристальная пещера → небесный храм. Промежутки между ними растут (90 → 1800), на каждом острове можно приземлиться и восстановить стамину. Между зонами светятся огоньки-подсказки.
- 13 детальных существ-животных из блоков (прыгают и покачиваются), доход от $1/сек до $75K/сек. Продажа = доход × 60.

## Звуки
Игра сразу играет встроенные звуки Roblox (запасные, с другим тоном). Свои звуки и музыка уже готовы в папке `sounds/`:
click, coin, collect, buy, error, grab, deliver, flap, splash, divine, levelup, music (фоновая, по кругу).
1. В Studio: **View → Asset Manager → Bulk Import** → выбери все файлы из `sounds/`.
2. ПКМ по каждому звуку → Copy ID.
3. Вставь ID в `Config.Sounds` (поле `id`, например `id = "1234567890"`) и пересобери.
Пересоздать звуки: `python3 tools/make_sounds.py`.

## Донат: как настроить
1. Опубликуй игру.
2. [Creator Dashboard](https://create.roblox.com/dashboard/creations) → твоя игра → **Monetization**:
   - **Passes**: создай 5 Game Pass и выстави цены: Золотое имя 5, 2x прибыль 12, +5 слотов 25, +50% стамины 39, VIP 59.
   - **Developer Products**: Мешочек 19, Сумка 49, Сундук 99, Хранилище 199, Удача сервера 19.
3. Скопируй ID каждого товара в `src/ReplicatedStorage/Shared/Config.lua` (поля `id = 0`).
4. Пересобери файл (`python3 build.py`) или вставь новый Config прямо в Studio.

Пока `id = 0`, в Studio покупка выдаётся бесплатно как тест (до выхода из игры). В опубликованной игре такие товары не продаются.

## Структура
```
src/
  ReplicatedStorage/Shared/Config.lua    весь баланс: цены, доходы, острова, крылья, донат
  ServerScriptService/Main.server.lua    запуск сервера
  ServerScriptService/Services/
    DataService        сохранение в DataStore
    MapBuilder         карта из блоков
    PlotService        базы игроков
    CreatureFactory    модели существ
    BrainrotService    спавн, захват, доставка, божественный
    UpgradeService     прокачка и продажа (проверка на сервере)
    MonetizationService  Game Pass и Developer Products
    CharacterVisuals   крылья и золотое имя
  StarterPlayer/StarterPlayerScripts/
    FlightController   полёт и стамина
    UIController       интерфейс
build.py                                 собирает .rbxlx
```

Если у тебя Rojo, папку `src` можно синхронизировать и без `build.py`.
